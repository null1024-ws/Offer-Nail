# Offer-Nail

面向秋招求职者的 Chrome / Edge 本地填写插件：把简历整理成加密档案，在招聘表单上预览后批量填写。

站点：https://null1024-ws.github.io/Offer-Nail （英文：https://null1024-ws.github.io/Offer-Nail/en/）

首次发布：仓库 Settings → Pages → Source 选 GitHub Actions，然后等待 `Deploy GitHub Pages` 工作流完成。

**插件只填写，永不自动提交申请。** 扫描版 PDF（无文字层）暂不支持 OCR，请改为手动录入。

## 隐私

- 简历、主密码和映射规则都只留在这台电脑上，不创建账号，也不上传档案。
- 权限只有 `activeTab`、`scripting`、`storage`。不会申请所有网站的永久读取权限。
- 内容脚本只接收你在预览里确认要写入的最小字段，不会把完整档案注入网页。
- 备份文件始终是密文；没有正确主密码无法恢复。遗忘主密码只能清除本地数据后重建。

## 安装（本地试用包）

先构建并打包（开发者机器）：

```bash
corepack pnpm install
corepack pnpm zip
corepack pnpm zip:edge
```

产物：

- Chrome 未打包目录：`.output/chrome-mv3/`
- Edge 未打包目录：`.output/edge-mv3/`
- Chrome 压缩包：`.output/offer-nail-0.1.0-chrome.zip`
- Edge 压缩包：`.output/offer-nail-0.1.0-edge.zip`

### Chrome

1. 打开 `chrome://extensions`
2. 打开「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择 `.output/chrome-mv3`（若你拿到的是 zip，先解压再选里面的扩展目录）

Chrome 137 及更新版本已移除 `--load-extension` 命令行，请用上述界面加载。

### Edge

1. 打开 `edge://extensions`
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选择 `.output/edge-mv3`

请用干净的浏览器配置或新的配置文件加载，避免和其他扩展互相干扰。

## 初始化

1. 点击工具栏图标，若尚未建立档案，点「打开设置页」。
2. 设置至少 12 位、同时包含字母和数字的主密码，并确认你理解：主密码无法找回。
3. 创建空白档案后，可在设置页导入本地 PDF / DOCX，或直接手动编辑。
4. 导入结果必须逐项校对。未确认的候选不会写入可填写档案。

## 填写招聘表单

1. 打开目标招聘网站的在线简历页，或本地测试表单。
2. 点击插件图标，输入主密码解锁。
3. 需要时选择岗位变体，再点「扫描当前页」。
4. 在预览中检查「页面字段 → 档案字段 → 拟填值」、置信度、冲突和敏感标记。
5. 高置信、非敏感、页面为空的字段会默认勾选；敏感项和已有值默认不改。
6. 确认后插件写入所选字段并高亮结果。请你自己检查，再亲手提交。
7. 若页面结构未变，可用「撤销本次填写」恢复原值。

测试夹具（开发用）：对 `tests/fixtures/forms` 起任意静态服务，浏览器打开 `http://127.0.0.1:<端口>/application-form.html`。

## 备份与恢复

- 设置页可导出加密备份 JSON。请把文件和主密码分开存放。
- 恢复前会预览档案名称和版本，确认后才会覆盖当前保险库。
- 「彻底删除」会清除本地保险库、网站规则和附件，且需要勾选确认。

## 支持边界

当前版本**不会**：

- 自动点击提交、登录、验证码或绕过反自动化限制
- 识别扫描件 / 图片简历
- 保证兼容某一个招聘系统的全部自定义控件
- 填写封闭 Shadow DOM、富文本编辑器或文件上传控件（会标明不支持）
- 提供云同步、账号或远程 AI 解析
- 支持 Firefox、Safari 或手机浏览器

页面跳转或表单结构变化后，撤销可能失效，插件会提示而不是乱写。
