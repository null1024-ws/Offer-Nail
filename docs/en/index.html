01 · Capabilities

One vault many forms

  1. Local vaultThe key stays on this computer

    Resume files, structured records, and site rules stay encrypted on device. There is no account and no cloud copy to leak.

  2. Import reviewParse is only a draft

    PDF and DOCX are read locally into candidate fields. Unchecked values never enter the fillable profile.

  3. Confirmed fillSee it then write it

    Preview shows page field, profile field, and proposed value. Nothing is written until you confirm, and the extension never submits.

  4. Job variantsSame facts different wording

    The master profile keeps identity facts. Variants override summary, intent, and descriptions instead of cloning the whole resume.

  5. Site rulesCorrect once remember next time

    Mapping fixes are stored per site on this machine. If the page changes enough, the rule falls back to confirmation instead of silent fills.

02 · Principles

Conservative by default

  1. 1 Nothing leaves this deviceParsing, encryption, and mapping run in the extension. Permissions are only activeTab, scripting, and storage.
  2. 2 Fill never submitThe extension can write inputs and highlight results. Submit, login, and captcha stay in your hands.
  3. 3 Mappings stay explainableEvery preview shows page label to profile field to proposed value. Low confidence and conflicts stay unchecked.
  4. 4 Fills can be undoneOriginal values are kept before writing. Undo works if the page structure is unchanged; otherwise you get a warning.
  5. 5 Sensitive fields stay offPhone and email matches are not selected by default. Referees and compliance statements require an explicit opt-in.

04 · FAQ

Answer these first

How is this different from Autofill or a job site parser?
Autofill stores logins. Site parsers often upload the file. Offer-Nail keeps a structured vault on this computer and writes the current page only after you confirm.
Is it free?
Yes. The source is Apache-2.0. You build the Chrome and Edge trial packs yourself.
Will it submit applications for me?
No. It fills fields you confirm. You still press submit.
What permissions does it need?
Only activeTab, scripting, and storage. It does not ask for permanent access to every site.
Can I import a scanned resume?
No. PDFs without a text layer are not OCR'd. Enter those fields by hand.
Is it on the Chrome Web Store?
Not yet. Build the unpacked directory from the repo and load it at chrome://extensions.
Who is this not for?
Anyone who needs cloud sync, Firefox or Safari, or unattended mass apply. It also does not promise every custom widget on every ATS.

File issues on GitHub. Do not paste resume text or the master password.
