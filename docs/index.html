01 · 能力

一次整理 多次复用

  1. 本地保险库钥匙留在这台电脑

    简历原文、结构化档案和站点规则都加密留在本机。没有账号，也没有云端副本可丢。

  2. 导入校对解析只是草稿

    本地读取 PDF 或 DOCX 后生成候选字段。你未勾选的内容不会进入可填写档案。

  3. 确认填写看见才写入

    预览里能看到页面字段、档案字段和拟填值。确认后才改表单，并且永不代你提交。

  4. 岗位变体同一事实 不同说法

    主档案保存身份事实。变体只覆盖简介、意向和经历描述，避免复制整份简历。

  5. 站点规则改过一次就记住

    你纠正的字段映射按网站保存在本地。页面结构大变时会降级为待确认，而不是静默乱填。

02 · 原则

默认保守

  1. 1 数据不出设备解析、加密和映射都在扩展里完成。权限只有 activeTab、scripting 和 storage。
  2. 2 只填写不提交插件可以写入输入框并高亮结果。提交、登录和验证码仍由你亲手完成。
  3. 3 映射可解释每一次预览都展示页面标签到档案字段再到拟填值。低置信和冲突默认不选。
  4. 4 填写可撤销写入前记下原值。页面结构未变时可以恢复；结构变了会提示而不是乱写。
  5. 5 敏感字段默认关手机、邮箱等敏感项即使匹配也不默认勾选。推荐人和合规声明需你主动启用。

04 · 问答

先回答这几句

和浏览器自动填充、招聘网站自带解析有什么不同？
自动填充只记账号口令；网站解析常把文件上传到对方服务器。Offer-Nail 在本机维护结构化档案，确认后才写入当前页。
这个插件收费吗？
不收费。源码以 Apache-2.0 发布，可自行构建 Chrome 与 Edge 试用包。
会不会自动提交申请？
不会。插件只填写你确认的字段。提交按钮始终由你点击。
需要哪些权限？
只有 activeTab、scripting 和 storage。不会申请对所有网站的永久读取权限。
扫描件简历能导入吗？
不能。没有文字层的 PDF 不会做 OCR，请改为手动录入。
能在 Chrome 网上应用店安装吗？
还没有上架。请从仓库构建未打包目录，在 chrome://extensions 里加载。
不适合谁用？
需要云同步、Firefox / Safari、或希望无人值守投递的人。也不承诺兼容某个招聘系统的全部自定义控件。
